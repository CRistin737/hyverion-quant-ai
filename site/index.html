An AI trading lab that proves itself on paper first

AI agents analyze QQQ, a deterministic risk engine has the final word, and every improvement is validated before it is promoted.

Clone on GitHub Download for macOS

Features

  • AI agents

    Analysis runs on Sonnet and decisions on Opus, through your own Claude or Codex subscription. A critic reviews every proposal.

  • Deterministic risk

    • Risk profiles in % of equity
    • Native broker stop on every position
    • Weekly loss limit and drawdown stop
    • Emergency flatten

  • Paper on QQQ

    Trades on Alpaca Paper over a year-long campaign. It improves itself only after passing replay, out-of-sample and shadow validation.

The app

Get started

Terminal 
git clone https://github.com/CRistin737/hyverion-quant-ai.git
cd hyverion-quant-ai
uv sync
cd app && pnpm install && pnpm tauri dev

Requirements

  • macOS 14+
  • Python 3.12 + uv
  • Node 22 + pnpm
  • Rust (stable)
  • A Claude or Codex subscription
  • A free Alpaca Paper account
