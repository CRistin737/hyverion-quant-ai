# Recovery runbook

The UI must explain the exact state and next safe action for provider and source
failures. Secrets are entered only through the native Keychain form or the VPS secret
manager. Repeated rate limits pause a connector; they do not increase polling pressure.

If a provider is unavailable, no new AI-dependent trade is authorized. Deterministic
protective exits and exchange-native stops remain active. If data is stale, the source
is excluded from new proposals until freshness is restored.
