| 2026-09-14 | One primary subscription plus ordered subscription fallbacks through one `ModelRouter` gateway | Prevents agents from choosing providers, prevents API billing from appearing as a silent fallback, and fails closed after chain exhaustion. |

| 2026-09-14 | Self-improvement creates reviewable proposals only | Production code and risk controls require human approval. |
